## 🚀 About

IntroText AI helps users respond to messages faster and more naturally by generating smart, context-aware reply suggestions. Instead of staring at a blank text box, users get relevant reply options instantly — tailored to tone and context.

## ✨ Features

- 💬 Context-aware reply generation
- ⚡ Instant suggestions with a responsive UI
- 🎨 Clean, minimal interface built with Tailwind CSS
- 📱 Fully responsive design across devices

## 🧰 Tech Stack

**Frontend:** Next.js, TypeScript
**Styling:** Tailwind CSS
**AI/Model:** Google Antigravity
**Deployment:** Vercel

## 🏗️ How It Works

1. User inputs a message or conversation context
2. The app processes this input and queries Google Antigravity to generate reply suggestions
3. Multiple natural, context-aware reply options are returned
4. User selects and copies the reply that fits best

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/dayalwarshlok/introtext-ai.git
cd introtext-ai

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Add your API key

# Start the development server
npm run dev
```
